# 🎬 Movie Recommender System
A Content-Based Movie Recommender built with Python and Streamlit.

## 🚀 Features
- Recommends 10 similar movies using Cosine Similarity.
- Fetches real-time posters from the TMDB API.
- Modern "Glassmorphism" UI with a cinematic background.

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Streamlit, Pandas, Scikit-learn, Requests
- **Data Source:** TMDB API

## ⚙️ Setup
1. Clone the repo
2. Install requirements: `pip install -r requirements.txt`
3. Run the app: `streamlit run app.py`
